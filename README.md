## 📌 Project Overview
An intelligent, multilingual platform connecting Scheduled Caste beneficiaries (annual income <= ₹5.00 Lakhs) with concessional credit and education schemes (Micro Finance, Term Loans, Educational Loans), routing applicants to eligible Channel Partners (SCAs, PSBs, RRBs, NBFC-MFIs) in good standing.

### Core Modules
1. **Smart Scheme Recommender:** Deterministic eligibility rules + LLM-based plain language explainability.
2. **Dynamic Financial Calculator:** Scheme-tailored live EMI computation honoring moratoriums (3-12 mos) and concessional interest rates (6.5%-15%).
3. **Geo-Spatial Channel Partner Locator & Router:** Map-based partner discovery filtered by distance and real-time NPA / fund-utilisation standing.
